## 問題

「直近のログ（最新20件）」のテーブルが見にくい原因：

1. **列が多すぎる（9列）** — 1261pxでも各列に十分な幅がなく、ヘッダー文字（「操作」「投げ銭」「結果」「日時」「デバイス」）が1文字ずつ縦に折り返されている
2. **バッジの縦折れ** — `whitespace-nowrap` が無いため「閲覧のみ」「レンタカー」「シェア」などが文字単位で折り返され、行高が異常に高い
3. **同じ情報の重複** — 「車種：コンパクト / 24h / 400km / desktop」など、ほとんどの行が同じ値（デフォルト値）で情報量が低い
4. **長いテキストの省略不足** — 流入元 `lovable.dev` などはOKだが、`Direct/直接アクセス…` は途中で切れて読みにくい

## 改善方針

### A. 列構成の整理（9列→7列）
- **「車種・時間・距離」を1セルに統合** → `コンパクト / 24h・400km` の2行表示
- **「操作」「結果」を1セルに統合** → アイコン+ラベルのバッジ1個に
- **「投げ銭」「日時」はそのまま**
- **「流入元」「デバイス」はそのまま**（ただしデバイスはアイコン化）

最終列構成：
```
利用条件 | 流入元 | デバイス | ステータス | 投げ銭 | 結果 | 日時
```

### B. 表示の安定化
- すべてのバッジ・短いラベルに `whitespace-nowrap` を付与し縦折れ防止
- ヘッダーセルにも `whitespace-nowrap` を付与
- 「結果」セルは `シェア` / `レンタカー` / `-` をアイコン+短い文字で固定幅
- 日時を `MM/DD HH:mm` の短縮表示に変更（年は省略、ツールチップで完全表示）

### C. デバイスのアイコン化
- `desktop` → 🖥️ Monitor アイコン
- `mobile` → 📱 Smartphone アイコン
- `tablet` → Tablet アイコン
- ツールチップでテキスト名表示

### D. 行ごとの視認性
- ホバー時のハイライトを少し強める
- 数値（時間・距離）は等幅フォント（`tabular-nums`）で右寄せ

## 技術詳細

**変更ファイル**: `src/components/admin/ComparisonAnalytics.tsx` のみ

主な変更点：
- `<TableHead>` / `<TableCell>` に `whitespace-nowrap` を付与
- 「車種・時間・距離」セルを統合し2行レイアウトに
- 「操作」列を削除し、「結果」セルに状態を統合（操作なし＝「閲覧のみ」薄色バッジ、操作あり＝結果バッジ）
- デバイス列に `lucide-react` の `Monitor` / `Smartphone` / `Tablet` アイコンを使用
- 日時を `Intl.DateTimeFormat` で `MM/DD HH:mm` に短縮、`title` 属性に完全な日時
- 数値セルに `tabular-nums text-right` を付与

## 期待される結果

- 1261pxビューポートで全列が横スクロールなしで表示される
- バッジ・ラベルが1行に収まり、行高が一定になる
- 同じ情報の繰り返しが減り、差分が一目でわかる
